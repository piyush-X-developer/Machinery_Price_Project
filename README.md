# 🚜 Machinery Price Project

A beginner-friendly Python project that helps users check estimated prices for common agricultural machinery.

## ✨ Features

- Choose a machine by number or name
- View an estimated price range
- Case-insensitive machine names
- Handles invalid input
- Keep searching until you choose `q` to quit

## 🛠️ Technologies

- Python 3

## ▶️ How to run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

## 📋 Example

